# GeoPedia 功能记录

已实现. 当前接口以 [GeoPedia 写作说明](geopedia.md) 为准.

- 入口为 GeoPedia, 网站路径 `/geopedia/`, 写作目录 `content/geopedia/`.
- 栏目顺序为 Ring, Schm, Stck, 高阶对象. 高阶对象合并展示 Drvd 和 Spct, 保留原有编号前缀和文件目录.
- 每个文件调用一次 `encyclopedia`, 记录名称, 定义, 简介, 性质与不变量.
- 性质使用 `([光滑], [紧合])` 内容列表, 显示为标签. 不变量使用 `([名称], [内容])` 成对列表, 别名也接受内容块. 一般讨论写在 `content: [...]`, 按需要使用正文和小节.
- 保留分类浏览和关键词搜索, 已移除类别, 布尔性质和数值范围筛选.
- 沿用跨篇引用, 前后项, 自动更新, MathML, 图形缓存和静态发布.
