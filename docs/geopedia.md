# GeoPedia 写作说明

入口为主导航的 `GeoPedia`, 地址为 `/geopedia/`. 支持分类浏览和关键词搜索, 不再提供类别, 性质或数值范围筛选.

## 新建对象

```sh
npm run new:object -- Ring0001 "环或代数名称"
npm run dev
```

文件创建于 `content/geopedia/Ring/Ring0001.typ`, 不覆盖已有文件. 每个文件独立编译为一个网页, 例如 `/geopedia/Ring0001/`. 文件名决定编号和网址, 修改名称不会改变网址.

栏目按以下顺序显示. 每个编号前缀独立使用 `0001` 到 `9999` 的四位编号:

| 目录和编号前缀 | 大类 |
| --- | --- |
| `Ring` | 环和代数 |
| `Schm` | 概形 |
| `Stck` | 叠 |
| `Drvd`, `Spct` | 高阶对象 |

`Drvd` 与 `Spct` 共用高阶对象栏目, 各自的编号和文件目录保留. 栏目内先列 Drvd, 再列 Spct, 各自按编号升序, 前后项链接可以在两者之间连续浏览.

文件直接放在对应类别目录下. 下划线或点开头的文件与目录作为草稿, 不发布. 写法示例在 `content/geopedia/Schm/_example.typ`.

## 模板与内容列表

每个文件导入模板并调用一次 `encyclopedia`, 无需再写 `#show: note`:

```typst
#import "../../geopedia-template.typ": *

#encyclopedia(
  name: [对象 $X$],
  aliases: ([另一个名称], [别名 $Y$]),
  introduction: [简要介绍这个对象.],
  base: [说明基域, 基底或相对态射.],
  definition: [写下对象的定义或构造.],
  properties: (
    [光滑],
    [紧合],
    [在 $k$ 上几何连通],
  ),
  invariants: (
    ([维数], [$n$]),
    ([某个群 $G$], [$ZZ$]),
  ),
  content: [
    在这里写一般讨论, 可以有多个段落和公式 $X$.

    == 补充说明
    #proof[也可以使用已有的证明环境.]
  ],
)
```

`name` 和 `definition` 必填, 其他项可省略. 名称, 简介, 定义, 别名和性质均使用 Typst 内容块 `[...]`, 可以包含公式.

**性质的每一项直接写成 `[性质]`, 外面用 `(...)` 包成列表.** 页面按书写顺序显示为标签, 自动换行. 只有一项时写作 `properties: ([光滑],)`. 适用条件可以直接写在内容中, 详细说明放在 `content` 中.

**不变量的每一项写成 `([名称], [内容])`.** 页面按书写顺序显示为键值列表, 名称和值都可以包含公式.

```typst
properties: (
  [Noether],
  [整闭],
  [在 $k$ 上有限型],
),
invariants: (
  ([某个数值], [0]),
  ([另一个数值], [-2]),
  ([某个表达式], [$H^*(X)$]),
),
```

空列表写作 `()`, 也可以省略整个参数. 不变量的值仍可直接使用 `true`, `false`, `none` 或数字, 分别显示为是, 否, 未记录或对应数值. 不变量仍兼容字符串键的字典写法.

别名写作 `aliases: ([Another name], [别名 $X$])`, 用于关键词搜索. 只有一个别名时写作 `aliases: ([Another name],)`. 构建器从编译后的内容提取搜索文字, 数学字母也可用普通字母搜索.

## 一般讨论

`content: [...]` 用于写不适合放在性质列表中的一般讨论. 非空时显示在不变量之后的讨论栏目, 对应 `<discussion>` 标签; 默认 `content: []`, 不生成空栏目.

这里可以自由写段落, `==` 小节, 公式, 定理, 证明, 交换图和折叠内容, 也可以引用其他对象或笔记. 小节会加入目录, 正文会加入关键词搜索. 不变量自身的补充说明仍可用 `invariant-notes: [...]`.

## 浏览与引用

栏目内按目录和编号顺序浏览, 页底提供同一栏目的上一个 / 下一个链接. 搜索匹配编号, 类别, 名称, 别名和正文, 包括性质标签和不变量的键值. 多个关键词以空格分隔时同时匹配. 搜索词保存在网址的 `q` 参数里, 从对象页返回时恢复. 无 JavaScript 时仍可浏览所有分类和对象.

文稿或百科都可以按编号引用对象:

```typst
#geopedia("Ring0001")
#geopedia("Ring0001", target: <properties>)
#geopedia("Ring0001")[自定义链接文字]
```

导入笔记模板后即可使用 `geopedia`, 默认链接文字为对象编号和名称. `object-ref` 是同一函数的原有名称, 仍然可用.

固定栏目标签为 `<construction>`, `<properties>`, `<invariants>`, 非空讨论栏还有 `<discussion>`. 自写定理可以添加普通标签, 本条目内用 `@label`, 跨条目用 `geopedia(..., target: <label>)`.

百科中引用文稿时, 路径从 `content/notes/` 根目录填写:

```typst
#note-ref("笔记本名/笔记标题", target: <my-theorem>)
```

引用文字和反向引用自动更新. 删除或转为草稿后, 引用变成普通文字; 恢复文件后链接恢复.

## 预览与发布

`npm run dev` 自动响应新增, 修改和删除文件. `npm run build` 生成静态站点, 继续使用原有 GitHub Pages 发布流程. 源文件下载, 打印和编译缓存保持可用.

旧版的目录和模板名已统一为 `geopedia` / `geopedia-template.typ`. 性质统一改写成 `properties: ([光滑], [紧合])` 内容列表, 数值和其他不变量放在 `invariants` 中的键值对. 更新程序后需要重启已经运行的预览进程.
