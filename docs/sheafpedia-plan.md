# sheafpedia 功能计划

状态: 第一版已实现. 实际接口和完整参数见 [sheafpedia 写作说明](sheafpedia.md).

## 已实现

- 主导航新增 sheafpedia, 中文标题为几何对象手册.
- 五类目录 `Schm`, `Stck`, `Drvd`, `Spct`, `Ring` (环和代数), 文件名为类别前缀加四位编号, 范围 `0001..9999`.
- 每个文件调用一次 `encyclopedia`, 名称和编号分开, 名称变化不改变 URL.
- 名称, 简介, 基底约定, 定义与构造, 性质说明, 不变量说明接受 Typst 内容; 公式导出为 MathML.
- 光滑, 紧合等 16 个可选布尔参数, 区分 true, false, none; 自定义性质字典.
- 维数等 5 个可选数值参数, 保留 0, 负数和小数; 自定义数值字典与内容不变量字典.
- 分类浏览和关键词搜索, 一项布尔性质与一项数值范围可组合筛选, 查询保存在 URL 中.
- 同类按编号生成上一个 / 下一个链接, 返回手册时恢复检索条件.
- `object-ref` 与 `note-ref` 跨栏目引用, 自动链接文字, 标签链接和反向引用.
- 新增, 修改, 删除, 草稿转换与恢复自动更新; 共用现有 Typst 编译与图表缓存.
- 新建命令 `npm run new:object -- Schm0001 "对象名称"`, 草稿写法示例及参数文档.
- 沿用宋体与纸面主题, 手机布局, 无 JavaScript 浏览, 源文件下载, 打印和 GitHub Pages 静态发布.

## 当前约定

性质是作者记录的数据, 不进行数学推断. 相对性质的基底或态射在 `base` 中说明. 未填写的性质省略于列表, 页面提示尚未记录; 不等同于 false. 三个正文栏目保留固定锚点, 方便稳定引用.

每个大类独立编号, 不自动重排. 初始目录为空, 不把测试数据或示例作为正式对象发布.
